# COVID-19 Impact Analysis

## 📌 Project Overview

This project analyzes the impact of COVID-19 in India using state-wise daily data.

The objective of this project is to identify trends in confirmed cases, recoveries, deaths, and active cases across different states and visualize the impact of the pandemic through data analysis techniques.

---

## 🎯 Objectives

- Analyze COVID-19 trends across Indian states.
- Study daily confirmed, recovered, and deceased cases.
- Identify states with the highest impact.
- Visualize pandemic growth patterns.
- Generate insights from historical COVID-19 data.
