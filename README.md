# COVID-19 Impact Analysis Dashboard

## 📌 Project Overview

COVID-19 Impact Analysis Dashboard is an interactive data visualization project developed to analyze and monitor the impact of the COVID-19 pandemic using state-wise data. The dashboard provides meaningful insights into confirmed cases, recoveries, deaths, and essential healthcare commodities through dynamic charts and visualizations.

The project was developed using Python, Dash, Plotly, Pandas, and Bootstrap to create an easy-to-use web-based analytical dashboard for exploring COVID-19 trends across different states.

---

## 🎯 Project Objectives

* Analyze COVID-19 statistics across multiple states.
* Visualize confirmed, recovered, and deceased cases.
* Monitor state-wise pandemic impact.
* Explore healthcare resource availability.
* Provide interactive visual insights for better decision-making.

---

## 🚀 Key Features

### Dashboard Summary Cards

The dashboard displays:

* Total Cases
* Active Cases
* Recovered Cases
* Total Deaths

### Interactive Visualizations

#### State-wise Analysis

Interactive bar charts showing:

* Total Cases
* Hospitalized Cases
* Recovered Cases
* Deceased Cases

#### Commodity Analysis

Visualization of healthcare resources such as:

* Masks
* Sanitizers
* Oxygen Availability

#### Zone Distribution Analysis

Interactive pie charts representing:

* Red Zone
* Orange Zone
* Green Zone
* Blue Zone
